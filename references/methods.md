# 机会研究与竞品拆解操作框架

## A｜赛道痛点→产品机会

### 1. 痛点聚类

对 5–8 个痛点逐项记录：用户要完成的具体任务 / 卡住的环节 / 现有替代 / 后果 / 真实证据条数（若有）/ 用户语言（真实或模拟需标记）/ 强度高、中、低 / 证据可信度。按样本频率排序；没有采样数据，按假设优先级排序并明确声明。

聚类避免空泛词：“不会使用AI”太宽；“在收到具体任务后，不知道把零散资料整理成一份可交付的PPT”才有购买场景。

### 2. 替代方案缺口

逐个痛点至少对照：免费教程/搜索、通用AI聊天、成品模板/资料、软件订阅、外包/人工服务，选实际相关项。检查以下缺口：
- 学了仍不会用：缺操作路径、适用场景、错误排查。
- 拼装成本高：多个软件/资源难衔接。
- 输出不稳定：缺验收标准和示例。
- 太泛/不适配：没有对应职业或场景。
- 付费后交付不足：只给信息不给可使用成果。

不要假定每个市场都存在这些缺口；要用资料或用户输入论证。

### 3. 机会设计

不少于4项（数据贫乏时作为候选假设），每项按如下顺序：

`产品名称｜目标用户与触发场景｜交付物/用户能得到的可见结果｜形态（数字资料/模板/Skill/小工具/服务）｜建议测试价（人民币）｜获客内容示例｜为什么此时值得试（有证据或标推断）｜竞争程度及根据（低/中/高）｜最大不确定性`。

非行情的**起步测试价**可参考以下启发式，不是平台实时价：
- 轻量资料/清单：¥9–39
- 可直接编辑的结构化模板：¥19–99
- 有明确输入输出、可实际运行的 Skill 工作流：¥29–199
- 单功能交互小工具：¥19–99/月 或 ¥39–199 买断（取决于服务成本）
- 带人工交付的定制服务：¥199–999+（按工时和范围核算）

定价必须跟价值、验证、维护成本和同类竞品比对。若无法证明高价值，不要用高价倒推购买意愿。

### 4. 推荐与取舍

优先考虑：痛点明确且迫切、触发频繁、可展示前后对比、交付可重复、获客场景自然、启动低成本、7天内能做最小验证。最后明确为什么推荐第1名、不推荐其他项，不要“都值得做”。

## B｜竞品/笔记九维拆解

对每项用**事实→解释→可操作的启示**结构写，避免只给大词。

1. **一句话定位**：把[谁]在[何时]的[困难]转化为[可见结果]。
2. **购买者画像**：情境、熟练度、预算/时间约束；未知时标假设。
3. **支付动机**：省时间、省试错、降低心理负担、提高交付确定性；区分宣称收益和真实交付。
4. **流量来源**：内容种草、搜索意图、店铺承接、私域等，只写有线索的推断；看标题关键词、发布时间及可见入口。不得假定后台转化路径。
5. **包装亮点**：标题钩子、封面可视化、首屏前后对比、权益、价格锚点；未看到封面不可声称封面优秀。
6. **可借鉴**：问题切入、演示顺序、交付结构、体验设计；不复制原创内容或品牌识别。
7. **缺口**：适用边界不清、交付示例少、售后/适配问题、专业门槛等，仅在证据支撑下说“存在”，否则用“值得验证”。
8. **差异化≥3条**：按人群细分、结果标准化、场景化交互、持续更新、价格与服务等不同轴，写出最低实施版本。
9. **四项10分制与总评分**：产品力（35%）、包装力（25%）、流量潜力（25%）、竞争友好度（15%）。总评分为已评项目加权均分，四项齐全时权重之和为100%；缺项需注明覆盖率。另报告**竞争难度**（10=极难），按 `竞争友好度=11-竞争难度` 换算后才参与总分，防止方向颠倒。每项评分附理由与证据可信度。没有信息可以“不评分”，不可硬打分。

## D｜完整闭环的推荐摘要结构

**一句话结论**：推荐[产品]，面向[人群]，通过[交付方式]在[场景]解决[问题]。

**证据质量**：来源数、时间窗、哪些是核实/假设。

**对比**：至少4个候选，仅列用户场景/交付物/测试价/竞争/验证难度。

**竞品**：有核实链接才做B全维拆解；没有链接可讨论替代方案类型，不冒充真实竞品。

**评分和选择**：给出7维评分（能评分的才计分），拒绝低证据下的“必赚”。

**7天3步验证**：
1. 核实：访谈/观察真实需求，记下可复核反馈，尽量跨独立用户。
2. 测试：只做能展示核心结果的1页样机/样例/最小Skill；发布符合规则的内容或触达真实潜在用户，展示真实交付。
3. 决策：预设观察指标（例：有效私信/试用完成/询价/真实付款）和停止条件。阈值是实验假设，不是行业基准；无进展则改定位或停止。

## 避免失败的输出检查

- 有真实需求证据吗，还是只因为趋势热？
- 提出了能拿到手或真能运行的东西吗？
- 把竞品标题/封面/销量想象成事实了吗？
- 价格是行情还是测试假设？
- 有不可替代的差异化吗？
- 是否给出可验证且可停止的行动？
